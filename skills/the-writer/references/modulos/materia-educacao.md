# Módulo: textos e matérias de educação

Herda `_base-materia.md`.

## Quando usar
Reportagem, explicador ou artigo sobre escola, ensino superior, políticas educacionais, aprendizagem, carreira e formação.

## Perfis prontos
- **Padrão: "a reportagem que mostra a sala de aula"** = Eliane Brum (principal) + piauí + jornalístico + acolhedor.
- **Explicador de política educacional** = Nexo + Vox + explicativo. Ex.: "o que muda com o novo ensino médio".
- **Ensaio** = bell hooks + The Atlantic + analítico. Educação como prática e como ideia.
- **Divulgação para pais e professores** = Mario Sergio Cortella + Morning Brew + didático + conversa de bar.

## Referências específicas da área
- **Eliane Brum**: escuta de quem vive o problema (aluno, professor, família) antes do dado.
- **bell hooks** (*Ensinando a transgredir*): linguagem acessível para teoria pedagógica.
- **Porvir** (portal brasileiro de inovação em educação): exemplo prático de escola real.
- **"This Is Water" (David Foster Wallace)**: para textos sobre o sentido de aprender.

## Limites da área
- Dados com fonte e ano: INEP (Censo Escolar, Saeb, Enem), IBGE (PNAD Educação), PISA/OCDE.
- Menores de idade: nunca identificar aluno sem autorização dos responsáveis; preferir nome fictício sinalizado.
- Distinguir evidência de pesquisa de experiência pontual de uma escola.
- Política educacional muda: marcar `[CONFIRMAR vigência]` para leis, BNCC, calendários.

## Clichês proibidos nesta área
"a educação é a base de tudo" · "transformar vidas" · "escola do futuro" · "nativos digitais" · "aprender a aprender" sem explicar · "professor herói".

## Checklist final
- [ ] Há pelo menos uma voz de quem vive o tema (fornecida pelo usuário).
- [ ] Dados com fonte e ano.
- [ ] Nenhum menor identificável.
- [ ] O texto explica o "e daí?" para o leitor.
